Task 0: Responsive Typography
Created a webpage with headings and paragraphs. Used CSS media queries to change the heading size: small on mobile, medium on tablet, and large on desktop.

Task 1: Responsive Layout with Media Queries
Created three boxes using CSS Grid. Used custom media queries to display one box per row on mobile, two on tablet, and three on desktop. Bootstrap was not used for this task.
Task 2: Bootstrap Responsive Columns
Used Bootstrap’s 12-column grid to arrange three novel cards. Each card occupies 12 units on mobile, 6 on tablet, and 4 on desktop. This produces stacked cards on mobile, two cards followed by one on tablet, and three cards in one row on desktop.

Task 3: Bootstrap Navigation Bar
Created a Bootstrap navbar with a logo on the left and navigation links on the right. On smaller screens, the links collapse into a hamburger menu. Bootstrap JavaScript allows the button to open and close the menu.

Task 4: Combined Responsive Page
Combined the Bootstrap navbar, novel cards, personal information sidebar, and footer. Used Bootstrap Grid to place the novels on the left and sidebar on the right on desktop, with sections stacked on smaller screens. Added custom media queries to adjust font sizes, spacing, and the visibility of an optional paragraph.
